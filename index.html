Accessible multi-select treeview

This is a prototype of an accessible multi-select tree for filtering data by geographic region. It follows the WAI-ARIA Authoring Practices Guide tree view pattern: native tree semantics (tree, treeitem, group), tri-state checkboxes expressed with aria-checked, a roving tabindex, and full keyboard support. It is built to behave correctly with NVDA + Chrome, JAWS + Chrome and VoiceOver + Safari – in semantics and focus management, not only visually. Plain HTML, CSS and JavaScript, no dependencies and no build step.

Keyboard

Open the field with Enter or Space on the “Geographic regions” button, Tab through the search box, the result buttons and the filters to reach the tree. Escape anywhere in the panel closes it and returns focus to the button (in a non-empty search box it first clears the box). In the search box, Enter jumps to the next result and Shift+Enter to the previous one. The tree itself is a single tab stop and uses the keys below.

Keyboard support for the treeview
KeyAction
Right ArrowExpands a collapsed parent; on an expanded parent moves focus to its first child; does nothing on a leaf.
Left ArrowCollapses an expanded parent; otherwise moves focus to the parent node.
Down Arrow / Up ArrowMoves focus to the next / previous visible node.
Home / EndMoves focus to the first / last visible node in the tree.
Space or EnterToggles the checkbox of the focused node. Checking a parent checks all of its descendants; ancestors become checked, unchecked or partially checked.
*Expands all sibling nodes at the same level as the focused node.
Any printable characterMoves focus to the next visible node whose label starts with that character.
